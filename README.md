## Sobre

Este projeto é meu portfólio pessoal, criado com foco em uma experiência
visual minimalista, responsiva e moderna.

Além de apresentar meus projetos, o desenvolvimento também serve como
prática de arquitetura de componentes, TypeScript, UI/UX e desenvolvimento
frontend moderno.
